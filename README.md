# SEMED — Protótipo do Portal da Educação

## Publicar no seu GitHub

1. Extraia este ZIP.
2. Envie todos os arquivos extraídos e a pasta assets para a raiz do repositório. Não envie apenas o ZIP.
3. index.html deve ficar na raiz, junto de style.css, app.js e data.js.
4. No repositório, abra Settings > Pages. Selecione Deploy from a branch, branch main e pasta / (root), e salve.
5. Aguarde a publicação e use o endereço exibido pelo GitHub Pages.

Repositório indicado: https://github.com/viniciusmaneita/SEMED---prot-tipo-/

## Conteúdo

O pacote contém oito páginas: Início, Secretaria, Escolas, página de cada escola, Calendário, Notícias, Documentos e Contato. A equipe da escola inclui direção, coordenação e professores. Busca, filtros, calendário e leitura de conteúdos funcionam no navegador.

## Personalizar

- data.js: escolas, equipes, notícias, eventos e documentos demonstrativos.
- style.css: cores, tamanhos e layout responsivo.
- app.js: interações e exibição dos conteúdos.
- assets/: imagens locais. Preserve os nomes ou atualize os caminhos.
- Arquivos HTML: estrutura, menus e textos de cada página.

Cada escola utiliza escola.html?id=IDENTIFICADOR, com seu conteúdo definido em data.js. Não é necessário compilar nem instalar dependências. Para ver localmente, extraia o conteúdo e abra index.html.

## Limites do protótipo

As escolas, nomes, funções, fotografias, notícias e datas são demonstrativos. Não há painel administrativo, banco de dados, matrícula, notas, frequência ou envio de mensagens. O formulário apresenta uma prévia da mensagem, sem enviá-la. As preferências de leitura e contraste ficam apenas no navegador. Adapte os conteúdos com a autorização e validação da Secretaria antes de uma publicação institucional.

As imagens ilustrativas foram obtidas do Unsplash e estão incluídas. As fontes Manrope e DM Sans são carregadas pelo Google Fonts, com Arial como alternativa.
